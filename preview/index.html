01 Live TypeScript · Canvas · Web Audio hitsound.vivlos.dev ↗ Repository ↗

Hitsound Studio

An FL Studio-style hitsound editor for osu! mappers, in the browser.

The problem

Hitsounding in osu! means juggling sample sets, additions, volumes and custom indices across hundreds of timing lines. The usual workaround is a dummy 18-key mania diff in Mapping Tools, which says mappers want lanes; the workflow just isn't there.

What it does

A channel-rack of lanes, each bound to a sample set, addition, index and volume, over a waveform with BPM-snapped grid and ghost notes from your other diffs. Exports a clean [Hitsounds] diff and can copy hitsounds into the mapset without touching slider velocity. Runs entirely client-side.

02 Live TypeScript · Canvas · Vite steal.vivlos.dev ↗ Repository ↗

steal-framework

Checks whether an osu! map was stolen from another map of the same song.

How it works

Give it a map link, ID or .osz. It pulls every other map of that song from the Hinamizawa mirror and compares rhythm timing, object positions and slider shapes — including flipped, rotated and shifted copies — then points at the exact stretches that match, on a playfield overlay you can scrub through.

Lore ヴィブロスについて

Why vivlos.dev?

The name comes from Vivlos (ヴィブロス) from Umamusume: Pretty Derby. There's no deep meaning behind it: I like Vivlos, I liked the name, and apparently I liked it enough to call the domain vivlos.dev — and I don't even play Uma.

Colophon

  • Set in Torus Pro (osu!'s typeface) and Maple Mono. Colours are osu!lazer's own palette.
  • Static files on GitHub Pages; a Cloudflare Worker proxies the osu! API, Lanyard provides Discord presence.
  • Glass by liquidglass (WebGL). Otherwise no frameworks, no trackers — hand-written HTML and CSS.
