PROJECT_01 STABLE / DAILY USE Hardware Patch

Repository ↗

veikk-s640-zero-smoothing

Kernel-level input smoothing bypass for graphic tablets in competitive rhythm games.

The Friction

Consumer drawing tablets are engineered for artists: the firmware intentionally injects algorithmic smoothing and moving averages to make hand strokes silky. In osu!, however, that smoothing translates directly into 15–30 milliseconds of input lag. When snapping to 280 BPM jump patterns, that delay turns clean hits into misses.

The Investigation & Hack

Dissected the USB HID report packets sent across the Linux input subsystem. Traced the packet stream where raw coordinate deltas were being altered before delivery to `/dev/input/event*`. Patched the kernel input driver to strip the interpolation buffers, passing unmodified 1:1 hardware polling straight to the compositor at sub-millisecond report intervals.

PROJECT_02 ACTIVE Terminal Application
TypeScript React / Ink MPV IPC
Repository ↗

youtube-music-cli

Terminal UI player for YouTube Music built with React, Ink, and headless MPV control.

The Friction

Running full web browsers or Electron-packaged music players while compiling code or playing demanding games is pure waste. I wanted instant keyboard search, queue controls, and lightweight background audio playback that lives inside my terminal multiplexer without hogging memory.

The Architecture

Engineered using React and Ink for reactive terminal UI rendering, connected to a headless MPV instance via Unix domain sockets (IPC). Handles real-time search queries, gapless audio streaming, keyboard navigation, and theme customization while maintaining minimal CPU overhead.

ry5088-flasher

Lightweight flashing utility for custom rhythm keypad microcontrollers and firmware patches.

The Motivation

Proprietary vendor software for configuring custom gaming keypads is frequently Windows-only, bloated, or reliant on shady web drivers. Built a minimal command-line utility to flash custom firmware over serial directly from Linux.

LORE & COLOPHON 【ヴィブロスについて・余白】

SITE NOTES

Why vivlos.dev?

The domain name originates from Vivlos (ヴィブロス), an Umamusume character. There is no profound philosophy behind it: I simply like Vivlos's character design and aesthetic, liked the rhythm of the word, and registered the domain.

The funny thing is that I don't even actively play the gacha game. It's just a personal corner of the internet where things that interest me—systems programming, custom drivers, rhythm gaming, and Japanese visual culture—coexist without needing to justify themselves to a corporate template.

Colophon

  • Typography: `Zen Kaku Gothic New` (body and display) & `Maple Mono` (telemetry and code).
  • Hosting: Static repository deployment on GitHub Pages with Cloudflare Worker proxy for live osu! API telemetry.
  • Craft: Zero UI libraries, zero trackers, zero bloat. Hand-authored HTML & CSS.
