Veikk S640 web flasher

Flashes over USB through the stock Veikk updater at 0x0800D800. Only the app area is written; the updater, settings and tags pages are never touched. To flash again later, the running firmware has to answer the updater trigger (09 04 2F EB 00 00 00 00 C0). Stock and every patched build here do. Chromium browsers only (Chrome, Brave, Edge). On Windows the updater (28e9:0189) needs the WinUSB driver once (Zadig). Docs · SHA256SUMS
