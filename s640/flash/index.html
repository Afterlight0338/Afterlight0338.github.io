Flash a Veikk S640 from the browser

No Pico, no screwdriver. Uses Veikk's own updater · how it works · SHA256SUMS

This browser can't talk to USB devices. Open this page in Chrome, Edge or Brave on a computer (not a phone, not Firefox, not Safari).

1Pick the firmware

firmwarepenwhat it does

2Put the tablet in update mode

  • Plug the tablet straight into the computer, not through a hub.
  • Quit OpenTabletDriver, the Veikk driver and any other tab using the tablet.
  • Press the button, pick S640 in the box that pops up, press Connect.

Tablet already shows up as 28e9:0189 (left in update mode)? Skip to step 3.

3Flash it

Press the button and pick 28e9:0189. Takes about 30 seconds. Don't unplug the tablet or close this tab until it says done.

Nothing shows up in the box / "access denied"

Linux: your user needs access to the tablet. Add this as /etc/udev/rules.d/70-veikk-s640.rules, then unplug and replug:

SUBSYSTEM=="hidraw", ATTRS{idVendor}=="2feb", TAG+="uaccess"
SUBSYSTEM=="usb", ATTRS{idVendor}=="28e9", ATTRS{idProduct}=="0189", TAG+="uaccess"

Windows: step 3 needs the WinUSB driver on the updater once. After step 2, run Zadig, Options → List All Devices, pick the device with ID 28E9 0189, driver WinUSB, Install Driver. Then step 3.
